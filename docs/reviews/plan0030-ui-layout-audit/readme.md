# 웹 전체 UI 배치 점검

Date: 2026-10-13
Baseline: `c58a0b3` (`main`)

## 확인 방법과 범위

실제 Devspace 백엔드·일회용 PostgreSQL·로컬 OIDC 테스트 계정으로 로그인했다. 검토용 프로젝트 2개, 작업 3개, 일지·문서·마일스톤·링크를 실제 API로 만들고 화면을 캡처해 직접 검토했다. 운영 계정 데이터나 성공 응답 mock을 사용하지 않았다. 기존 real runner의 실행·정리 절차를 임시 점검 모듈에서 재사용했으며 임시 실행 파일은 제거했다. 앱과 기존 테스트 소스는 변경하지 않았다.

- 1440×900 및 390×900: 홈, 프로젝트 목록/상세, 작업 보드, 개발일지 목록/상세, 자료실, 문서 Viewer/Editor 9종.
- 추가: 홈 초기 상태(1280×900), 모바일 로그인, 프로젝트 추가·링크 추가·일지 검색 모달.
- 총 23개 화면 캡처. [관찰 데이터](observations.json)에 viewport와 실제 제목·버튼을 기록했다.
- 이번에는 정상 데이터 배치와 일부 입력 모달을 점검했다. 모든 오류·충돌·빈 상태, 모든 편집 모달, 가상 키보드, 320px 및 native 확대는 전수 검증하지 않았다. 작업 추가 모달은 버튼명 탐색 불일치로 열지 못했고 기록에 `notOpened`로 남겼다.
- 문서 밖 가로 overflow는 수집한 정상 페이지에서 발견되지 않았다. 작업 보드의 잘린 열은 **보드 내부 가로 스크롤**이며 페이지 전체 overflow와 구분한다.
- full-page 모달 캡처에서 viewport 아래 배경이 보이는 것은 캡처 범위에 따른 것으로, 실제 backdrop 오류로 분류하지 않았다.

## 유지할 구성

- [개발일지 상세](journal-detail-390.png): 본문과 연결 글 순서 및 이동 버튼 유지.
- [검색 모달](journal-search-390.png): 한 버튼 진입·임시 조건·적용 계약 유지. 공통 헤더 축소 영향만 검증.
- [문서 Viewer](document-390.png), [Editor](editor-390.png): 읽기/작성 폭과 본문 정렬 유지. 제목에 한정된 포커스 표시는 제거 대상이 아니다.
- [로그인](login-390.png): 주요 액션이 명확하고 작은 화면에서 충돌이 없어 재설계하지 않는다.

구현 우선순위와 완료 기준은 [PLAN-0030](../../plans/PLAN-0030-workspace-ui-layout.md)을 따른다.
