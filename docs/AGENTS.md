# AGENTS.md

This directory contains project documentation.

Follow all applicable AGENTS.md files when creating or modifying documentation. More deeply nested instructions take precedence when they conflict.

## Structure

- `agents/` — repository workflow and centralized source instructions, with scopes mapped in the root `AGENTS.md`
- `plans/` — implementation and migration plans
- `decisions/` — technical and architectural decisions
- `architecture/` — current system structure and design
- `guides/` — repeatable development workflows
- `references/` — visual and external reference materials

## Rules

- Keep documentation consistent with the current codebase.
- Avoid duplicating information across documents.
- Use relative repository paths when referencing files.
- Use Markdown and lowercase kebab-case file names.
- Place documents in the directory that best matches their purpose.
